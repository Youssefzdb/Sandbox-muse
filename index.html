Sandbox Muse — Bridge

Reverse-polling mode: Vercel does not call the sandbox. It queues your command, the sandbox worker pulls it, runs it (allowlist only, test-project dir only), and streams the output back here, line by line.

Token is typed by you and kept only in your browser (localStorage). It is never in this repo. If no JOB_TOKEN is set in Vercel, leave it empty.
